## 사람이 판단할 것

1. **`instant = false`**(`app/blog/[slug]/page.tsx:13`). 계획에 없던 설정입니다. 다른 방법은 본문을 `<Suspense>`로 감싸고 로딩 화면을 두는 것인데, 이 페이지는 모든 값이 상수이고 시안에 로딩 화면이 없어 이 방법을 택했습니다. 두 방법 중 하나를 정해 주세요.
2. **페이지 끝 목차 현재 위치.** 푸터가 없어 페이지가 시안보다 87px 짧습니다. 그래서 1280×900 화면에서는 "입력과 렌더링 분리하기"가 현재 항목이 되지 못합니다. "정리"는 시안에서도 현재 항목이 되지 못합니다. 푸터를 만들 때 함께 볼지, 맨 아래까지 스크롤하면 마지막 항목을 켜는 규칙을 더할지 정해 주세요.
3. **같은 결과를 다시 복사할 때**(`components/CodeCopyButton.tsx:10`). "복사됨"인 동안 다시 누르면 상태 값이 같아 타이머가 처음 클릭 기준으로 끝나고, 화면 낭독기도 다시 읽지 않습니다. 시안도 처음 타이머를 지우지 않아 같은 동작입니다. 누를 때마다 새로 시작하게 할지 정해 주세요.
4. **글 메타 줄 클래스 중복.** `flex flex-wrap items-center gap-2 text-[13px] text-subtle tabular-nums`가 `app/blog/[slug]/page.tsx:55`와 `HomeRecentPosts.tsx`의 `POST_META_CLASS_NAME`에 똑같이 있습니다. 공용 컴포넌트로 뺄지 정해 주세요.
5. **오른쪽 목차 랜드마크.** 시안대로 `<aside>`라 데스크톱에서는 목차가 navigation 랜드마크로 잡히지 않습니다. 본문 위 목차는 `<nav>`입니다. `<aside>` 안을 `<nav>`로 감쌀지 정해 주세요.
6. **코드 블록 키보드 스크롤.** 긴 코드가 가로로 스크롤되는 `<pre>`에 포커스가 가지 않습니다. 스크롤 영역에 자동으로 포커스를 주지 않는 브라우저(Safari 등)에서는 키보드로 스크롤할 수 없습니다. `tabIndex={0}`과 파일 이름 라벨을 줄지 정해 주세요. 그러면 Tab 순서가 하나 늘어납니다.
7. **이름.** 네 가지 이름을 그대로 둘지 정해 주세요.
   - `--kw`·`text-kw`: 시안 이름을 따랐는데 약어입니다. `--code-keyword`가 더 잘 읽힙니다.
   - 페이지의 `postBody`: 본문 컴포넌트와 목차의 묶음이라 `postBody.Body`로 읽혀 헷갈립니다.
   - `POST_BODIES` 값 타입: 조회 표 안에 익명으로 적혀 있습니다.
   - `PAGER_DIRECTIONS` 값 타입: 조회 표 안에 익명으로 적혀 있습니다.
8. **한 번만 쓰는 값과 쓰지 않는 토큰.**
   - `FULL_BODY_POST_TITLE`(`app/blog/[slug]/page.tsx:93`)은 한 곳에서만 쓰는데 모듈 상수로 빠져 있습니다.
   - `@theme`의 `--color-body`는 `.post-body`가 `var(--body)`를 직접 써서 쓰는 곳이 없습니다.
