## 검증 결과

**사이클:** 2/3 · **종료 사유:** 미검증 없음
**최종 확인:** 통과

| 단계 | 수정 수 | 검증됨 | 실패 남음 |
| ---- | ------- | ------ | --------- |
| 구현 | 5       | 5      | 0         |
| QA   | 1       | 1      | 0         |
| 리뷰 | 3       | 3      | 0         |

- **디자인:** 시안 `design/blog-a.html`의 `.intro`와 1280px·375px, 라이트·다크 네 조합에서 비교했습니다. 계산된 스타일 24개 속성이 모두 같고, 요소 11개의 위치·크기가 1px 안에서 같습니다.
- **기능:** 아래 동작을 브라우저에서 눌러 보며 확인했습니다.
  - GitHub 새 탭 열기
  - 이메일·RSS를 눌러도 주소가 그대로임
  - 더 알아보기를 누르면 `/about`으로 이동
  - hover 시 accent 색, 누르는 동안 0.97 축소
  - Tab 이동 순서와 포커스 링
  - 동작 줄이기 설정에서 전환 꺼짐
  - 콘솔 에러 없음
- **정적 검사:** `pnpm lint`, `tsc --noEmit`, `prettier --check`가 통과했습니다.

### 검증 중 고친 것

| 단계 | 내용                                                                                                                                            |
| ---- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| QA   | `text-sm`이 줄 높이 20px을 함께 넣어 시안(22.4px)보다 hero가 2~3px 짧았습니다. `text-[14px]`로 바꿔 body 줄 높이 1.6을 물려받게 했습니다        |
| 리뷰 | "더 알아보기 →"의 화살표를 `aria-hidden`으로 숨겼습니다. 화살표만 따로 감싸면 버튼의 flex 간격이 끼어들어, 글자 전체를 한 `span`으로 감쌌습니다 |
| 리뷰 | GitHub 링크에 화면 낭독기용 "(새 탭에서 열림)"을 넣었습니다                                                                                     |
| 리뷰 | 클래스 상수 이름을 `LINK_BUTTON_CLASS_NAME`에서 `HERO_ACTION_CLASS_NAME`으로 바꿨습니다. 버튼에도 쓰이기 때문입니다                             |

## 사람이 판단할 것

1. **본문 폭 클래스 중복** — `app/page.tsx:5`와 `components/Header.tsx:12`에 `mx-auto max-w-[1080px] px-6 max-xs:px-4`가 똑같이 들어 있습니다. 한쪽만 바꾸면 헤더와 본문 폭이 어긋납니다. `globals.css`에 폭 토큰을 두거나 공용 래퍼를 만들 수 있지만, 이번 범위 밖의 두 파일을 고쳐야 해서 남겼습니다. 두 번째 페이지를 만들 때 정리할지 결정이 필요합니다.
