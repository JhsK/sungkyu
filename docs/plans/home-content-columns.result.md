### 검증 중 고친 것

| 단계 | 내용                                                                                                                                                                                                                                                    |
| ---- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| QA   | 태그 개수 `<small>`이 Tailwind 기본 스타일(80%) 때문에 10.4px로 작았습니다. 시안은 브라우저 기본값인 `smaller`(10.83px)를 씁니다. `text-[length:smaller]`로 맞췄습니다                                                                                  |
| 리뷰 | 카드가 떠오르는 이동과 `→`가 밀려 나오는 이동이 애니메이션 없이 바로 바뀌었습니다. Tailwind v4의 `translate-*`는 `transform`이 아니라 `translate` 속성을 바꾸기 때문입니다. 전환 대상을 `translate`로 고치고, 계획대로 속성과 시간을 한 번에 적었습니다 |
| 리뷰 | hover용 `→`가 카드·글 링크 이름 끝에 함께 읽혔습니다. 대체 텍스트를 비운 `content: '→' / ''`로 바꿨습니다                                                                                                                                               |
| 리뷰 | 태그 링크가 "JavaScript5"처럼 붙어 읽혔습니다. `aria-label`을 "JavaScript 5개"로 줬습니다                                                                                                                                                               |
| 리뷰 | 최근 TIL 날짜를 `MM.DD`로 바꾸는 식을 `toMonthDayDate` 헬퍼로 뺐습니다                                                                                                                                                                                  |

## 사람이 판단할 것

1. **등장 지연 식 중복**: `components/HomeRecentPosts.tsx:37`과 `components/HomeSidebar.tsx:29`에 `index * 50 + 80`이 똑같이 들어 있습니다. 공용 함수(예: `lib/motion.ts`의 `getRiseItemDelay({ index })`)로 모을 수 있지만, 이번 변경 파일 표 밖에 새 파일을 만들어야 해서 남겼습니다.
2. **이동 전환 시간 `240ms` 중복**: `components/HomeRecentPosts.tsx`의 카드와 `→`에 두 번 적혀 있습니다. `globals.css`에 `--dur-move` 같은 토큰을 둘지 결정이 필요합니다.
3. **섹션 제목·제목줄 클래스 반복**: `text-[15px] font-semibold text-muted`가 세 번, `mb-1 flex items-center justify-between gap-3`이 두 번 나옵니다. 시안의 `.section-label`·`.head-row`에 해당합니다. TIL·소개 페이지에서도 쓰이므로, 그때 공용 컴포넌트로 뺄지 결정이 필요합니다.
4. **`countTilsByTag`를 `Map.groupBy`로**: `components/HomeSidebar.tsx`의 헬퍼를 `[...Map.groupBy(TILS, (til) => til.tag)]`로 줄일 수 있습니다. 서버 컴포넌트라 Node 버전만 맞으면 됩니다.
5. **링크 이름 길이**: 카드와 글 목록은 링크 하나가 제목·요약·날짜·태그를 모두 감싸서, 화면 낭독기가 링크 이름을 길게 읽습니다. 시안 구조를 그대로 따른 결과입니다. `aria-labelledby`로 제목만 읽히게 할 수 있습니다.
6. **`aria-label="사이드"`**: 시안 값을 그대로 옮겼습니다. "최근 TIL과 태그"처럼 내용이 드러나는 이름으로 바꿀지 결정이 필요합니다.

## 확인하지 않은 것

- 레포에 테스트 러너가 없어 자동 테스트는 없습니다.
- 브라우저 MCP가 없어 Playwright 스크립트와 로컬 Chrome으로만 확인했습니다. Safari·Firefox는 확인하지 않았습니다. `content: '→' / ''` 문법은 Safari 17.4, Firefox 128 미만에서는 무효가 되어 hover `→`가 보이지 않습니다.
- 글·TIL 페이지가 없어, 링크를 눌렀을 때 404가 뜨는 것까지만 확인했습니다.
