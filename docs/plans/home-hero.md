# 계획: 홈 hero 섹션

홈(`/`) 헤더 아래에 시안 A의 소개 영역(hero)을 만듭니다. hero에는 직무 한 줄, 제목, 소개 문장, 링크 버튼 4개가 들어갑니다. 지금 홈은 빈 `<main />`이라 이 작업으로 홈의 첫 화면이 채워집니다.

**완료 조건**

- 데스크톱(1280px)과 모바일(375px)에서 시안 `.intro`와 크기·간격·색이 같습니다.
- 라이트·다크 테마 모두 시안의 색 토큰을 씁니다.
- GitHub는 새 탭에서 열리고, "더 알아보기 →"는 `/about`으로 이동합니다.
- 이메일·RSS 버튼은 시안 모습 그대로 두고, 누르면 아무 일도 일어나지 않습니다.
- `pnpm lint`와 타입 검사를 통과합니다.

## 입력 근거

- 디자인 시안: `design/blog-a.html`
  - 스타일: 90~97행(`.intro`, `.links`, `.link-btn`), 76행(`.eyebrow`), 88행(`.view`), 308~309행(누름 효과)
  - 마크업: 346~357행
- 디자인 인스펙터: `design/blog-a-inspector.html` (시안을 띄워 수치를 재는 도구, hero 전용 주석 없음)
- 사람 결정
  - 시안의 안내 토스트(293행, 771~774행)는 만들지 않습니다.
  - GitHub 주소는 `https://github.com/JhsK`입니다. 시안에는 `https://github.com/`만 있습니다.

## 현재 코드 상태

| 위치                            | 상태                                                                                                          |
| ------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| `app/page.tsx:1-3`              | `<main />` 하나만 렌더합니다                                                                                  |
| `app/layout.tsx:21-22`          | 모든 페이지에 `Header`를 먼저 렌더합니다. hero는 그 아래 `children`에 들어갑니다                              |
| `components/Header.tsx:12`      | 본문 폭 기준이 `mx-auto max-w-[1080px] px-6 max-xs:px-4`입니다. 시안 `.wrap`과 같으므로 hero도 이 값을 씁니다 |
| `app/globals.css:3-43`          | hero에 필요한 토큰(`fg`·`muted`·`border`·`accent`, `--dur`·`--ease`, `xs` 브레이크포인트)이 모두 있습니다     |
| `components/Icons/Search.tsx:1` | 아이콘 컴포넌트 패턴입니다. `size` 기본값 18, `aria-hidden`, `stroke="currentColor"`                          |
| `components/IconButton.tsx:20`  | 누름 효과(`active:scale-[0.97]`)와 전환 속성을 Tailwind로 옮긴 선례입니다                                     |

시안에는 있지만 코드에 없는 토큰은 `--subtle`, `--chip-*`, `--r-md`(10px)입니다. hero는 `--r-md` 하나만 쓰므로 토큰을 새로 만들지 않고 `rounded-[10px]`로 적습니다.

## 설계

### 구조

```text
app/page.tsx                 <main> 본문 폭·위아래 여백(시안 .view .wrap)
└─ components/HomeHero.tsx   hero 섹션 (서버 컴포넌트)
   └─ components/Icons/{Github,Mail,Rss}.tsx
```

- `HomeHero`는 홈에서만 씁니다. 나중에 홈에 글 목록(`.home-cols`)이 붙을 때 `app/page.tsx`에서 hero와 나란히 조립할 수 있게 별도 컴포넌트로 둡니다.
- 상태와 이벤트 처리가 없으므로 서버 컴포넌트로 둡니다.

### 링크 버튼

| 버튼          | 요소                                 | 동작                                         |
| ------------- | ------------------------------------ | -------------------------------------------- |
| GitHub        | `<a target="_blank" rel="noopener">` | `https://github.com/JhsK`를 새 탭으로 엽니다 |
| 이메일        | `<button type="button">`             | 없음                                         |
| 더 알아보기 → | `next/link`                          | `/about`으로 이동합니다                      |
| RSS           | `<button type="button">`             | 없음                                         |

시안은 이메일·RSS를 `href="#home"`인 `<a>`로 만듭니다. 그대로 옮기면 누를 때 주소에 `#home`이 붙으므로, 이동하지 않는 `<button>`으로 바꿉니다. 겉모습은 같은 클래스로 맞춥니다. 주소가 정해지면 `<a>`로 바꿉니다.

네 버튼이 같은 클래스를 쓰므로 클래스 문자열을 파일 하단 상수 하나로 둡니다. 요소 종류가 셋으로 갈려 배열 `.map`보다 JSX를 네 번 적는 편이 읽기 쉽습니다.

### 스타일 대응

| 시안                                                                    | Tailwind                                                                                                                                                  |
| ----------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `.view` `padding-block: 72px 96px`                                      | `pt-18 pb-24` (`<main>`)                                                                                                                                  |
| `.intro` 세로 간격 16px, 아래 56px, 아래 테두리                         | `flex flex-col gap-4 pb-14 border-b border-border`                                                                                                        |
| `.eyebrow` 14px·500·accent                                              | `text-sm font-medium text-accent`                                                                                                                         |
| `h1` `clamp(30px, 22px + 2.4vw, 40px)`, 1.3, 700, -0.02em, balance      | `text-[clamp(30px,22px+2.4vw,40px)] leading-[1.3] font-bold tracking-[-0.02em] text-balance`                                                              |
| `.lede` 최대 560px, muted, 17px                                         | `max-w-[560px] text-[17px] text-muted`                                                                                                                    |
| `.links` 간격 8px, 줄바꿈, 위 8px                                       | `mt-2 flex flex-wrap gap-2`                                                                                                                               |
| `.link-btn` 44px, 좌우 16px, 테두리, 10px 모서리, 14px·500, 아이콘 16px | `inline-flex h-11 items-center gap-2 rounded-[10px] border border-border px-4 text-sm font-medium` + 아이콘 `size={16}`                                   |
| hover 시 테두리·글자 accent, 누르면 0.97                                | `hover:border-accent hover:text-accent active:scale-[0.97]` + `transition-[color,background-color,border-color,transform] duration-(--dur) ease-(--ease)` |

h1의 `clamp` 안 `+`는 Tailwind가 공백을 넣어 주는지 구현 때 생성된 CSS로 확인합니다. 넣어 주지 않으면 `_+_`로 적습니다.

### 대안과 기각 이유

| 대안                                             | 기각 이유                                                      |
| ------------------------------------------------ | -------------------------------------------------------------- |
| 이메일·RSS 버튼을 빼고 GitHub·더 알아보기만 둔다 | 시안과 달라집니다. 주소가 생기면 다시 배치를 손봐야 합니다     |
| 이메일·RSS를 비활성(`disabled`) 버튼으로 둔다    | 흐린 모습이 되어 시안과 달라집니다                             |
| hero를 `app/page.tsx`에 바로 쓴다                | 홈에 글 목록이 붙으면 파일이 커집니다. 섹션 단위로 나눠 둡니다 |

### 변경 파일

| 파일                          | 작업                                                   |
| ----------------------------- | ------------------------------------------------------ |
| `app/page.tsx`                | `<main>`에 본문 폭·여백을 주고 `HomeHero`를 렌더합니다 |
| `components/HomeHero.tsx`     | 새 파일. hero 섹션과 링크 버튼 4개                     |
| `components/Icons/Github.tsx` | 새 파일. 시안 GitHub 아이콘                            |
| `components/Icons/Mail.tsx`   | 새 파일. 시안 이메일 아이콘                            |
| `components/Icons/Rss.tsx`    | 새 파일. 시안 RSS 아이콘                               |

이번에 하지 않는 일은 「후속 작업」에 모았습니다.

## 정책과 엣지 케이스

| 상황                             | 기대 동작                                                                              |
| -------------------------------- | -------------------------------------------------------------------------------------- |
| 이메일·RSS를 누름                | 주소·화면이 바뀌지 않습니다. 누름 효과만 보입니다                                      |
| `prefers-reduced-motion: reduce` | `globals.css:67-75` 규칙으로 hover 전환과 누름 효과가 꺼집니다                         |
| 화면 폭 480px 이하               | 좌우 여백 16px. 버튼은 줄바꿈되고 h1 크기는 30px까지 줄어듭니다                        |
| 다크 테마                        | 토큰으로 색이 바뀝니다                                                                 |
| `/about` 미구현                  | "더 알아보기 →"를 누르면 Next.js 기본 404가 뜹니다. 헤더 "소개" 링크와 같은 상태입니다 |
| 키보드 사용                      | 버튼 4개 모두 Tab으로 이동하고, `globals.css:60-64`의 포커스 링이 보입니다             |

## 미결 사항

1. **검증 방법** — 레포에 테스트 러너가 없어 단위 테스트는 쓰지 않습니다. `pnpm lint`·타입 검사와 브라우저 화면 비교로 확인합니다.
2. **의존성 설치** — 워크스페이스에 `node_modules`가 없습니다. lint·타입 검사 전에 `pnpm install`이 필요합니다.
